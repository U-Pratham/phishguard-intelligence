# PhishGuard Intelligence

Explainable cybersecurity threat investigation platform for analyzing suspicious URLs and scam messages using local heuristic detection, evidence correlation, and SQLite scan history.

## Current Stage (v0.1 - Local Heuristic Engine)
- **Backend**: FastAPI + SQLite (`phishguard.db`)
- **Detection**: Local URL heuristic analyzer & scam SMS/email message analyzer
- **Frontend**: React + Vite + Tailwind CSS + Recharts
- **Note**: All current detections are generated by the **Local Heuristic Engine** (no external threat-intel APIs or ML models yet). Scores are heuristic risk scores (0–100), not probabilities.

---

## Quick Start (Windows PowerShell)

### 1. Start the Backend
Open a terminal in `d:\Hack\PhisGuard`:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn backend.main:app --reload --port 8000
```
*(If PowerShell blocks `Activate.ps1`, run `.\venv\Scripts\python.exe -m pip install -r requirements.txt` and `.\venv\Scripts\uvicorn.exe backend.main:app --reload --port 8000`.)*

Backend will be live at `http://127.0.0.1:8000` (API docs at `http://127.0.0.1:8000/docs`).

### 2. Start the Frontend
Open a **second** terminal in `d:\Hack\PhisGuard\frontend`:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

Frontend will be live at `http://localhost:5173`.
